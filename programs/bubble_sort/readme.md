# Bubble Sort

## Description

This benchmark sorts an array of integers in ascending order using the Bubble Sort algorithm.

## Purpose

This program is used to verify:

- Memory read/write operations
- Comparison operations
- Nested loops
- Conditional branching

## Files

- `bubble_sort+_assembly.asm` – RISC-V assembly source
- `bubble_sort.mem` – machine code (copy to `machine_code.mem` in the simulator's working directory to run it)
