# Hardware Implementation

This directory is reserved for the future FPGA implementation of the **RV32I 32-bit Single-Cycle RISC-V Processor** on the **Digilent Basys 3 (Artix-7)** development board.

The processor has been functionally verified through simulation and successfully synthesized. Hardware implementation and on-board validation will be added in a future update.

Planned additions include:

- Basys 3 constraint file (`.xdc`)
- FPGA bitstream
- Hardware setup images
- Demonstration videos
- Hardware validation results
